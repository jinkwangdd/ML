# XGBoost Stock Predictor

## Overview
A Python application to predict short-term stock price movements using XGBoost, technical indicators, and financial ratios. It features an interactive Streamlit-based dashboard for data visualization, model training, evaluation, and backtesting.

## Features
*   **Data Collection**: Fetches historical stock prices for US (via `yfinance`) and KR (via `FinanceDataReader`) markets.
*   **Financial Data**: Integrates company financial statements (income, balance sheet, cash flow) for US stocks using `yfinance`.
*   **Feature Engineering**:
    *   Calculates a variety of technical indicators (RSI, MACD, SMA, Bollinger Bands).
    *   Computes key financial ratios (PER, PBR, ROE, Debt-to-Equity, Sales Growth, Net Income Growth).
    *   Generates target labels based on future price movements.
*   **Model Training**:
    *   Employs an XGBoost classifier for prediction.
    *   Includes Stratified K-Fold cross-validation.
*   **Model Evaluation**:
    *   Assesses model performance using Accuracy, ROC AUC score.
    *   Displays Confusion Matrix and Classification Report.
*   **Feature Importance**: Visualizes the most influential features for the model's predictions.
*   **Backtesting**: Implements a simple trading strategy based on model signals and evaluates its performance against a buy-and-hold baseline.
*   **Interactive Dashboard**: A Streamlit application allows users to input stock tickers, date ranges, and parameters, then view the analysis and results.

## Setup and Installation
1.  **Clone the repository** (or download the files):
    ```bash
    # If you have git installed:
    # git clone <repository_url> 
    # cd <repository_name>
    ```
    If you downloaded a ZIP, extract it and navigate to the project directory.

2.  **Create a virtual environment** (recommended):
    ```bash
    python -m venv venv
    ```
    Activate the environment:
    *   On macOS and Linux:
        ```bash
        source venv/bin/activate
        ```
    *   On Windows:
        ```bash
        .\venv\Scripts\activate
        ```

3.  **Install dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

## How to Run
1.  Ensure your virtual environment is activated and dependencies are installed.
2.  Navigate to the root directory of the project (where this README is located).
3.  Run the Streamlit application using the following command:
    ```bash
    streamlit run stock_predictor/app.py
    ```
4.  The application should open in your web browser. You can then input the desired stock ticker, date range, and other parameters to start the analysis.

**Note on DART API Key for Korean Financials**: The current application version has a placeholder for loading Korean financial data via CSV or skips it. Full integration with OpenDARTReader for live KR financial data would typically require a DART API key to be configured.

## Modules

*   **`data_loader.py`**: Contains functions to fetch historical stock price data from `yfinance` (for US stocks) and `FinanceDataReader` (for Korean stocks). It also includes functionality to retrieve US company financial statements.
*   **`feature_engineering.py`**: Responsible for creating predictive features. This includes calculating various technical indicators (e.g., RSI, MACD, SMA, Bollinger Bands) using `pandas-ta`, computing financial ratios by combining statement data with price data, and generating binary labels for model training based on future price changes.
*   **`model_train.py`**: Handles the training of the XGBoost classification model. It includes Stratified K-Fold cross-validation, model evaluation (accuracy, ROC AUC, confusion matrix, classification report), and plotting feature importances.
*   **`backtest.py`**: Implements a simple event-driven backtesting engine. It takes trading signals (generated by the model) and historical price data to simulate trades, calculating portfolio value over time and comparing strategy returns against a buy-and-hold benchmark.
*   **`app.py`**: The main entry point for the user. It's a Streamlit web application that orchestrates the workflow: taking user inputs, calling other modules for data loading, feature engineering, model training, evaluation, and backtesting, and then displaying the results and visualizations in an interactive dashboard.
